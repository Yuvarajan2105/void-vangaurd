# VOID VANGUARD

**SPACE WAR · ASTEROID FRONT**

A 3D retro arcade space shooter built with Unity. Pilot a fighter jet through a drifting asteroid belt, hunt down the alien Boss ship, and destroy it along with every guard it sends against you.

## Download

Go to the [**Releases**](../../releases) page, download `VoidVanguard_v1.0_Windows.zip`, extract it, and run **Void Vanguard.exe**.

**Requirements:** Windows 10 or 11 (64-bit). A graphics card is recommended; on integrated graphics the game may run slower.

> Windows may show a SmartScreen warning the first time, because the game is not code-signed. Click **More info → Run anyway**.

## The goal

The Boss ship sits far away from where you start and summons mini alien ships to protect itself, one after another, for as long as you are in range. **You win only when the Boss and every mini ship are destroyed.** If your ship is destroyed first, it is Game Over.

## Controls

| Key | Action |
|---|---|
| **W** / **S** | Accelerate / decelerate |
| **A** / **D** | Move left / right |
| **Arrow keys** | Rotate the ship (pitch up/down, turn left/right) |
| **Space** (hold) | Fire |
| **Esc** | Pause / resume |

## Features

- Fighter-jet flight with banking turns and a chase camera.
- **Aim assist:** the aim ring turns **red** when an enemy is inside it and within range. Bolts fired while locked curve into the target.
- An asteroid belt streams across your path. Asteroids are physical objects: they bounce, damage ships, and break into smaller pieces with a fracture explosion.
- A stationary Boss that fires from the rim of its hull and summons guards while you are in range.
- Radar and screen-edge markers that point to enemy ships.
- On-screen messages such as "Boss Ship destroyed by the Player".
- A full galaxy skybox with nebulae and stars, a title screen, a pause menu, music and sound effects.

## Tips

- Cross the asteroid belt carefully: asteroids hurt, and touching the Boss's hull destroys your ship.
- Asteroids can damage enemy ships too. Use them.
- Keep moving. Mini ships chase you and ram for damage.

## Built with
